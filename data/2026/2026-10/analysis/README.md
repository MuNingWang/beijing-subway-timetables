# 2026-10 官方原始时刻表二级分析

本期是首次基线，原始材料采集于 2026-10-11；分析于 2026-10-12 进行。存档月份不代表时刻表生效月份。目前没有第二期原图，不能计算环比、同比，也不能验证 2025 年减班 20% 的说法。

直接读取 raw 中的 API JSON、HTML、图片。没有读取任何 OCR 缓存、OCR 分钟表或 normalized 数据。图片计数只识别小时标签和分钟项占位，不识别分钟数字。

## 已实现指标

1. 每方向/车站/日型的小时列次数：`hourly_counts.csv`；每项原图坐标在 `image_item_evidence.jsonl`。
2. 全天经过本站列次数及早峰 07–09、平峰 10–16、晚峰 17–19、夜间 21–次日01：`station_periods.csv`。区间左闭右开；00 时记作运营日第 24 小时。早晚峰/月度变化在有可比历史后计算。
3. 同站同方向工作日÷双休日班次比：`day_type_comparison.jsonl`，保留分子、分母与两张原图。
4. 站点供给差异：`spatial_comparison.jsonl` 与 `adjacent_station_checks.jsonl`。最少÷最多仅描述覆盖站点差异。`representative_sections.jsonl` 固定比较东四/东夏园、湾子/万盛东、望京/俸伯的同方向同日型服务量，用作中心/外围代表站候选指标；不独立证明交路类型。环线方向按原始官方站序归一化，1号线与八通线按贯通线路合并比较；保留原图方向名称。跨小时、始终点、折返、越站均可能造成差异。
5. 彩色标记计数：`color_markers.jsonl`。3张已对图例的样本按单图SHA-256提供小交路候选数量与比例，其他图片该值为 null。当前自动提取亮色填充标记；空心圈、虚线框、深色标记未作统一交路解释，“unmarked”不代表全程车。
6. 图片版本与异常报告：`version_events.jsonl`、`review_queue.jsonl`。本期版本事件文件为空，含义是无历史基线，不能解释成没有运营调整。
7. 高频服务形态：`station_summary.jsonl` 的 ≥12/15/20 班小时数、低于10班小时数、峰值小时与高峰/平峰比。统计只包括已观测的 06–23 整点小时；精确高峰起止不在当前证据范围。
8. 首末车服务跨度：`first_last_service.jsonl`。保留 API 的终到站、isHalf、首末车注释，以及 HTML 备选末班与表头；不合并不同交路，不自行推定日型。

## 证据与复算

每条图像结果携带原图相对路径、SHA-256、算法版本、源元数据路径、行与时刻项坐标。`image_catalog.jsonl` 区分图片材料与时刻表候选。校验摘要见 `validation.json`；固定图片抽样复核见 `sample_review.json`（若存在）。工具与测试位于采集工作区，未进入此数据仓库；本仓库不含运行工具。原始 OCR 文件保持原样，未将其标记为已纠错。

原始首末车重新解析保留空字段和备选末班，不沿用旧转录的过滤与移位结果，所以条数可以与 `processed/first_last.jsonl` 不同。统计文件不修改既有转录或校验报告。

## 已对原图核对的日型样本

东四站开往潞阳方向，工作日全天经过本站269列次，双休日160列次；07–09时分别39与16列次，17–19时分别44与22列次。这是同一期两种日型的差异，不能解释为历史减班。两张原图的各小时计数已列入固定目视样本；工作日红色填充与双休日黄色填充都在各自图例中表示草房终到，说明颜色解释必须绑定单图版本。这里记录的是时刻表列次数，不代表实际到站表现或载客容量。
